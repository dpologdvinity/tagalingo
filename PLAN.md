# Tagalingo — Version 1 Plan

Tagalingo is a gamified app for learning **Tagalog (Filipino) from English**, built in short
daily lessons. The mascot is **Tala** (Tagalog for "star"), a wide-eyed Philippine tarsier.

## Brief (what was asked vs. what I assumed)

**Asked for:** short lessons of mixed exercise types, streaks and daily goals, XP and a weekly
leaderboard, a skill path that unlocks in order, and hearts that refill over time. Lesson
exercises are generated by Claude from a word list and then reviewed by hand. The app must run
on a fresh machine with no third-party accounts.

**Assumed:**

- The target language is Tagalog, because the folder is named `tagalingo`.
- One course, for English speakers.
- The demo account doubles as a content reviewer, so every screen can be clicked through.
- All learners share one global weekly leaderboard; there are no tiered leagues in v1.

Fonts: **Lilita One** (bold condensed, in the spirit of jeepney sign painting) for headings only
and **Atkinson Hyperlegible** for everything else, chosen so learners can tell apart letters
and diacritics in an unfamiliar language. The one bold visual idea is the skill path drawn as a
jeepney route: each unit opens with a painted route placard and skills are stops along a
winding road. Copy mixes in small bits of Tagalog: _Tara na!_ ("Let's go!"), _Magaling!_
("Great job!"), and _Barkada League_ (barkada means friend group).

## Stack

- **Next.js 16** with the App Router, TypeScript (strict) and Tailwind v4.
- **Next.js 16 notes:** `proxy.ts` (formerly middleware) does a cheap session check, and
  `cacheComponents` is off because every screen is per-learner and dynamic.
- **Postgres 17** through **Prisma 7** (`prisma-client` generator plus the `@prisma/adapter-pg`
  driver adapter). Local dev uses `docker compose`.
- **Auth.js v5** with an email/password Credentials provider, JWT sessions, and bcrypt hashes.
  There is also a one-click demo login.
- **Zod** to validate exercise payloads, server-action inputs and generator output.
- **Anthropic SDK**, used only by the content generator and kept behind an interface with a
  local stub.
- **Vitest** for unit tests and **Playwright** for end-to-end smoke tests and screenshots.

## Data model

```
User          id, email, name, passwordHash, isReviewer, timezone, dailyGoalXp,
              totalXp, hearts, heartsUpdatedAt, currentStreak, longestStreak,
              lastStreakDay (YYYY-MM-DD in user's tz), createdAt
Course        id, slug, title, fromLang, toLang
Unit          id, courseId, order, title, subtitle, color
Skill         id, unitId, order, slug, title, emoji, description
Lesson        id, skillId, order, title
Word          id, skillId, tagalog, english, partOfSpeech, notes,
              exampleTl, exampleEn          ← the hand-written word list
Exercise      id, lessonId, order, type, payload (JSON, zod-validated per type),
              status DRAFT|APPROVED|REJECTED, source HUMAN|CLAUDE|STUB,
              generationRunId?, reviewedById?, reviewedAt?, reviewNote?
GenerationRun id, skillId, provider, model, requestedById, createdAt, error?
LessonAttempt id, userId, lessonId, startedAt, completedAt?, xpAwarded,
              mistakes, status IN_PROGRESS|COMPLETED|FAILED
AttemptAnswer id, attemptId, exerciseId, correct, answer (JSON), createdAt
LessonProgress userId+lessonId (unique), firstCompletedAt, timesCompleted
XpEvent       id, userId, amount, reason, createdAt   ← weekly leaderboard, daily goal
DailyActivity userId+day (unique), xp, lessons       ← streak calendar
```

**Exercise types** (each payload has its own zod schema):

1. `select_translation`: pick the right translation of a word or phrase from 4 options.
2. `word_bank`: build the translation by tapping word tiles (answer tiles plus distractors).
3. `match_pairs`: match 4–5 Tagalog words to their English meanings.
4. `fill_blank`: choose the word that completes a Tagalog sentence.
5. `type_translation`: type the translation. Matching ignores case, punctuation and accents,
   and allows one typo.

**Rules** (pure functions in `src/lib/game/*`, unit-tested):

- **Grading** happens on the server, through a server action, for every answer.
- **Hearts:** maximum 5. A wrong answer costs 1 heart, and one heart refills every 30 minutes.
  The refill is computed lazily from `heartsUpdatedAt`, so no cron job is needed. With 0 hearts
  you can't start a lesson, and a lesson in progress fails.
- **XP:** 10 per lesson, +5 for a perfect lesson, and +5 the first time you complete a lesson.
- **Streak:** goes up by 1 on the first lesson you complete each calendar day (in your
  timezone). Missing a day resets it to 1 on your next lesson.
- **Daily goal:** 10, 20, 30 or 50 XP per day, shown as a ring.
- **Weekly leaderboard:** sum of XpEvents since Monday 00:00 UTC, top 30 plus your own rank.
- **Unlocking:** lesson _n_ opens once lesson _n−1_ of the same skill is done. A skill's first
  lesson opens once every lesson of the previous skill is done. A skill without approved
  lessons shows as "Coming soon".

## Content pipeline (the hard part)

```
content/tagalog/course.yaml   hand-written units, skills, words + example sentences
          │
          ▼  ExerciseGenerator interface
   ┌──────────────┬───────────────┐
   │ ClaudeGenerator (Anthropic,   │  StubGenerator (deterministic templates
   │ JSON-schema tool output)      │  built from the word list, no network)
   └──────────────┴───────────────┘
          │  zod validation + content lint (answer in options, tiles cover answer, …)
          ▼
   Exercise rows with status DRAFT  ──►  /studio review queue (preview, edit, approve/reject)
          │
          ▼  npm run content:export
content/tagalog/exercises/*.json  (approved, version-controlled, loaded by the seed)
```

- The generator is chosen with `CONTENT_GENERATOR=claude|stub`. If that's unset, the app uses
  Claude when `ANTHROPIC_API_KEY` is set and the stub otherwise.
- Only `APPROVED` exercises are ever served to learners.

## Out of scope for v1

- Audio (listening and speaking exercises), plus TTS and speech recognition.
- OAuth providers, email verification, password reset and transactional email.
- Tiered leagues with promotion and relegation; friends and following.
- Streak freezes, gems or a shop, paid subscriptions and ads.
- Push or email reminders.
- Spaced-repetition practice; hearts are restored only by waiting.
- Multiple courses and localising the UI.
- Offline/PWA support and native apps.
- An admin UI for editing course structure; that's done in `course.yaml`.

## Version 1.1: richer lessons (done)

**Request:** match the kinds of lesson activities that apps like Ling and Rosetta Stone offer. Only
the activity types are matched. All sentences, dialogues and tips are written from
scratch for Tagalingo, and nothing is copied from those products.

| Activity              | How Tagalingo does it                                                                                                                     |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Listening             | New `listen_select` exercise: hear a Tagalog phrase, pick its meaning. Speaker buttons on Tagalog text throughout.                        |
| Picture matching      | Dropped after 1.1 shipped: emoji are open to interpretation (🌙 "good evening" or "night"?). Emoji stay on flashcards beside the meaning. |
| Speaking              | New `speak` exercise: say a sentence, graded on the speech-recognition transcript. "Can't speak now" always works and costs nothing.      |
| Dialogues / role play | New `dialogue` exercise: read a short conversation and choose the next line. Dialogues are hand-written per skill in `course.yaml`.       |
| Grammar notes         | A tips page per skill (`tips` in `course.yaml`), linked from the path.                                                                    |
| Pronunciation intro   | A "Sounds of Tagalog" guide page.                                                                                                         |
| Flashcards            | A words page per skill with flip cards and audio.                                                                                         |
| Review / milestone    | Practice sessions per skill or per unit, drawn from approved exercises. Practice earns XP, counts for the streak and wins back a heart.   |
| Chatbot               | "Chat with Tala": Claude behind a `ChatTutor` interface, with a scripted offline stub.                                                    |

**Audio** goes through a `SpeechProvider` interface. With `GOOGLE_TTS_API_KEY` set it uses Google
Cloud Text-to-Speech (fil-PH voices). Otherwise it falls back to the browser's built-in speech,
and if the device has no Filipino voice, the text is shown instead. **Speech recognition** uses
the browser's Web Speech API (Chrome and Edge support Filipino). Where it isn't available, the
speaking exercise offers only "Can't speak now".

**Data model changes:**

- The `ExerciseType` enum gains `listen_select`, `speak` and `dialogue` (`select_picture` was
  added and later removed by the `drop_picture_exercises` migration).
- `LessonAttempt` gains `kind` (LESSON | PRACTICE), an optional `skillId`/`unitId` scope, and
  `exerciseIds`, a snapshot of exactly what was served. Completion requires exactly that
  snapshot, which also replaces the "approved before start" check.

**Rules:**

- `speak` and `match_pairs` never cost hearts.
- Practice never costs hearts and works at 0 hearts.
- Finishing a practice session gives 5 XP (+5 if perfect) and restores one heart.

**Out of scope for 1.1:** finger tracing, which suits non-Latin scripts and isn't needed for
Tagalog, and human-recorded audio.
